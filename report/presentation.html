Project overview

This project develops reusable R functions for leave-one-out (LOO) validation of generalized linear models. Each subject is held out once, a model fitted to the other subjects predicts that subject’s outcome. The functions return the LOO predictions, prediction errors, MAE, and RMSE in an S3 result object.

Two sample datasets illustrate the same workflow: one with a continuous outcome and one with a binary outcome. Both contain the same 50 subjects and the same five predictor values. Only the outcome-generation model changes. The binary outcome is sampled from a Bernoulli distribution using a modeled probability, not by thresholding the continuous outcome. Predictor distributions do not determine the GLM family or link.

Predictor Generating distribution Parameters
x1 Normal Mean 0, SD 1
x2 Normal Mean 5, SD 5
x3 Poisson Rate 3
x4 Bernoulli Probability 0.3
x5 Uniform Minimum 0, maximum 10

For the continuous outcome, \(Y = X\beta + \varepsilon\), with \(\varepsilon \sim N(0,1)\). For the binary outcome, \(p = \operatorname{logit}^{-1}(X\beta)\) and \(Y \sim \operatorname{Bernoulli}(p)\). The design matrix includes an intercept. The two coefficient vectors are shown in the data-generation code below.

Code structure and execution order

The implementation follows the four tasks:

Function Main inputs Output or displayed result
fit_fun() Formula, training data, family function, link string Named vector of fitted coefficients
predict_fun() LOO coefficient matrix, original data, formula, family, link Response-scale predictions, errors, MAE and RMSE in a loo_results object
run_loo() Formula, full data, family, link, number of workers Runs all omitted-row fits and returns the result from predict_fun()
print.loo_results() Result object Prints MAE and RMSE, then invisibly returns the object
summary.loo_results() Result object Prints model settings, data dimensions and metrics, then invisibly returns the object
plot.loo_results() Result object, histogram bin count Uses R’s existing S3 generic to return a prediction-error histogram

Execution order

  1. Generate and save the two example datasets.
  2. Define the fitting function, prediction function, and S3 methods.
  3. Call run_loo() with a formula, dataset, family and link.
  4. For each row i, fit the model without that row by calling fit_fun().
  5. Bind the coefficient vectors into a matrix: row i belongs to the model that omitted subject i.
  6. Call predict_fun() to match each subject to its own omitted-row coefficients, apply the inverse link, and create the result object.
  7. Inspect the result using print(), summary(), and plot().

Parallel computation

With workers = 1, run_loo() uses lapply(). With more workers, it starts a PSOCK cluster (four workers by default), exports the required function and inputs, and runs the independent fits with parLapplyLB(). Tasks go to available workers dynamically, so the allocation need not contain exactly the same number of fits per worker. The returned list preserves the original row order. on.exit() closes the cluster when the function exits, including after an error. This example checks agreement between serial and parallel results. It does not benchmark a speed improvement.

Both datasets share the same 50 rows of predictors. The CSV files include an explicit intercept column, but the fitting formula uses only x1 through x5: R adds the model intercept automatically. Files use the existing Data/ folder.

Task 2: Fit one model and return its coefficients

family is a function such as gaussian or binomial. link is a string such as "identity" or "logit". model.frame() collects the formula variables, then model.matrix() and model.response() extract the design and outcome. The arguments to glm.fit() are lowercase x and y.

#' Fit a GLM and retain only its named coefficient vector.
#' @param formula A model formula with a single numeric response.
#' @param data A data frame containing the formula variables.
#' @param family A GLM family function, for example gaussian or binomial.
#' @param link A character string naming the link.
#' @return A named numeric coefficient vector.
fit_fun <- function(formula, data, family = gaussian, link = "identity") {
  if (!is.function(family)) {
    stop("family must be a function, such as gaussian or binomial.")
  }
  if (!is.character(link) || length(link) != 1L || is.na(link)) {
    stop("link must be one string, such as 'identity' or 'logit'.")
  }

  mf <- stats::model.frame(formula, data = data, na.action = stats::na.fail)
  X <- stats::model.matrix(attr(mf, "terms"), data = mf)
  y <- stats::model.response(mf)
  if (!is.numeric(y) || !is.null(dim(y))) {
    stop("Use a single numeric response (0/1 for the binary example).")
  }
  if (any(!is.finite(X)) || any(!is.finite(y))) {
    stop("Model variables must be finite and contain no missing values.")
  }

  fit <- stats::glm.fit(x = X, y = y, family = family(link = link))
  if (!isTRUE(fit$converged)) {
    stop("The GLM did not converge. Inspect the data and model specification.")
  }
  if (fit$rank < ncol(X) || any(!is.finite(fit$coefficients))) {
    stop("The model has coefficients that cannot be estimated uniquely.")
  }
  fit$coefficients
}

Task 3: Predict the omitted rows and create an S3 result

The coefficient matrix has one row per omitted observation and one column per model coefficient. The prediction for row i uses only row i of that matrix: sum(X[i, ] * beta[i, ]). Column names align the coefficients with the design.

The inverse link converts the linear predictor to the response scale. This is determined by the chosen family and link, regardless of the distributions of the predictors. For the binary example, predictions are probabilities.

Here bias follows the pseudocode’s direction: predicted minus observed. These are individual prediction errors, rather than an estimate of simulation bias across repeated datasets. MAE and RMSE use all rows. Failed fits stop the calculation rather than silently removing observations.

#' Make row-wise LOO predictions and assemble a result object.
#' @param beta Matrix whose ith row contains coefficients fitted without row i.
#' @param dat The original data frame, in its original row order.
#' @param formula The formula used in every fit.
#' @param family The family function used in every fit.
#' @param link The link string used in every fit.
#' @return An object of class loo_results.
predict_fun <- function(beta, dat, formula, family = gaussian,
                        link = "identity") {
  mf <- stats::model.frame(formula, data = dat, na.action = stats::na.fail)
  X <- stats::model.matrix(attr(mf, "terms"), data = mf)
  y <- stats::model.response(mf)

  if (!is.matrix(beta) || nrow(beta) != nrow(X) ||
      ncol(beta) != ncol(X) ||
      !setequal(colnames(beta), colnames(X))) {
    stop("beta must have one row per observation and matching model columns.")
  }
  beta <- beta[, colnames(X), drop = FALSE]
  family_spec <- family(link = link)
  eta <- rowSums(X * beta)
  pred <- family_spec$linkinv(eta)
  if (any(!is.finite(pred))) {
    stop("The model produced non-finite predictions.")
  }
  bias <- pred - y

  results <- list(
    formula = formula,
    family = family_spec,
    nrow = nrow(dat),
    ncol = ncol(dat),
    coefficients = beta,
    observed = y,
    predicted = pred,
    bias = bias,
    mae = mean(abs(bias)),
    rmse = sqrt(mean(bias^2))
  )
  class(results) <- "loo_results"
  results
}

#' @param x A loo_results object.
#' @param ... Additional method arguments.
#' @return The input object, invisibly.
print.loo_results <- function(x, ...) {
  cat("Leave-one-out prediction metrics\n")
  cat(sprintf("MAE:  %.6f\nRMSE: %.6f\n", x$mae, x$rmse))
  invisible(x)
}

#' @param object A loo_results object.
#' @param ... Additional method arguments.
#' @return The input object, invisibly, after displaying its summary.
summary.loo_results <- function(object, ...) {
  cat("Formula:", paste(deparse(object$formula), collapse = " "), "\n")
  cat("Data:", object$nrow, "rows and", object$ncol, "columns\n")
  cat("Family:", object$family$family,
      "| Link:", object$family$link, "\n")
  print(object)
  invisible(object)
}

# R already provides the plot() generic for S3 dispatch.
#' @param x A loo_results object.
#' @param bins Number of histogram bins.
#' @param ... Reserved for additional arguments.
#' @return A ggplot histogram of predicted minus observed errors.
plot.loo_results <- function(x, bins = 10L, ...) {
  ggplot2::ggplot(data.frame(bias = x$bias), ggplot2::aes(x = bias)) +
    ggplot2::geom_histogram(bins = bins, color = "white", fill = "steelblue") +
    ggplot2::labs(
      title = "LOO prediction errors",
      x = "Predicted - observed", y = "Count"
    ) +
    ggplot2::theme_minimal()
}

Task 4: Run LOO, using four workers by default

data[-i, , drop = FALSE] removes row i and keeps a data frame. parLapplyLB() assigns rows dynamically to available workers. It does not guarantee exactly equal work per worker. Its returned list stays in the input row order. on.exit() ensures that the cluster closes even if a fit fails.

#' Run one-row-at-a-time LOO validation.
#' @param formula A model formula.
#' @param data The complete data frame.
#' @param family A family function, for example gaussian or binomial.
#' @param link A link string.
#' @param workers Number of PSOCK workers. 1 runs serially for checking.
#' @return An object of class loo_results.
run_loo <- function(formula, data, family = gaussian, link = "identity",
                    workers = 4L) {
  if (!is.data.frame(data) || nrow(data) < 3L) {
    stop("data must be a data frame with at least three rows.")
  }
  if (!is.numeric(workers) || length(workers) != 1L ||
      !is.finite(workers) || workers < 1 || workers != floor(workers)) {
    stop("workers must be a positive integer.")
  }

  indices <- seq_len(nrow(data))
  if (workers == 1L) {
    res <- lapply(indices, function(i) {
      fit_fun(formula, data[-i, , drop = FALSE], family, link)
    })
  } else {
    cl <- parallel::makePSOCKcluster(as.integer(workers))
    on.exit(parallel::stopCluster(cl), add = TRUE)
    parallel::clusterExport(
      cl, c("fit_fun", "formula", "data", "family", "link"),
      envir = environment()
    )
    res <- parallel::parLapplyLB(cl, indices, function(i) {
      fit_fun(formula, data[-i, , drop = FALSE], family, link)
    })
  }

  # Avoid silently combining coefficient vectors with different model columns.
  same_columns <- vapply(res, function(b) {
    identical(names(b), names(res[[1L]]))
  }, logical(1))
  if (!all(same_columns)) {
    stop("The model columns changed between LOO fits.")
  }
  beta <- do.call(rbind, res)
  predict_fun(beta, data, formula, family, link)
}

Examples

These examples use numeric predictors, a numeric response, ordinary unweighted GLMs, and no missing data. Predictors with data-dependent transformations, new factor levels, offsets, or weights require additional handling and are outside this example’s scope. Convergence warnings remain visible for inspection.

model_formula <- Y ~ x1 + x2 + x3 + x4 + x5

cont_result <- run_loo(model_formula, cont, gaussian, "identity")
binary_result <- run_loo(model_formula, binary, binomial, "logit")

Test fixtures are generated within the tests. Running them does not regenerate the example CSV files or execute the rest of this report.
